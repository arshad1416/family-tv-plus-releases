# Family TV+ releases

Public distribution of signed Family TV+ Android TV APKs and update metadata only.

Application ID: `app.familytv.rdplus`. Source is maintained separately; this repository contains no application source or signing keys.

TV updates require the compatible Plus updater, explicit Update consent and Android installer confirmation. Downloaded APKs are verified against their SHA-256 digest, package, increasing version and installed signing certificate.

Family TV+ is designed for Android TV remote control. Phone compatibility is not tested.
